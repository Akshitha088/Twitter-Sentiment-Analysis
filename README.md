# 🧠 Twitter Sentiment Analysis using NLP

This project classifies tweets into **Positive**, **Negative**, or **Neutral** sentiments using **Python NLP techniques**.

## 🚀 Features
- Text cleaning (handles emojis, hashtags, and slang)
- Sentiment analysis using TextBlob
- Data visualization with Matplotlib 

## 🛠️ Tech Stack
- Python
- NLTK, TextBlob
- Pandas, Matplotlib


## 📊 Output
Visualizes sentiment distribution and saves the classified results to a CSV file.

## 📁 Files
- `twitter_sentiment_analysis.ipynb` — main notebook  
- `tweets.csv` — input dataset  
- `twitter_sentiment_output.csv` — output results
